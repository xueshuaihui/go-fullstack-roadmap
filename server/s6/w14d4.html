导出的权限口径：只导你读得到的行

昨天那句事故复盘其实有上下两半：「导出接口不读筛选参数，且只导当前用户的数据」。上半（不读筛选）昨天治了；下半今天治。导出权限的正确口径一句话：导出的行集合 = 该读者在列表里能看到的行集合——不多一行（guest 干脆不给导），不少一行（member 导的是家庭全量，不是「只导自己记的」）。两半合起来，「导出行数 = 查询行数」才在权限维度上也成立。

今日目标

知识讲义

1. 导出权限矩阵

角色能否导出行范围依据
owner√家庭全量，含所有私密行行级可见性的第二个例外读方（D13）
member√家庭全量，但私密行仅本人所记共账语义：列表能看到什么，导出就是什么
ward√同 member 口径有限写权限不影响读导出；可见性谓词一视同仁
guest×—限时只读、不可导出：403 + 1003

两条原则从矩阵里读出来：

  • 「只导自己」错在与列表不一致。member 在列表里看到的是全家人的非私密流水（家庭共账），点导出却只拿到自己记的那部分——用户视角就是「导出的账比我看到的少」，对账照样对不上。导出与列表必须同集合，这是「导出行数 = 查询行数」判据的另一半含义。
  • guest 拒绝是角色闸，不是行过滤。guest 可以在线看列表（限时只读），但导出是「把家庭数据带出大门」的动作，性质不同——整条接口对 guest 关门，403 + 1003（权限不足），不是给他导一份空文件。

2. 实现：一道闸 + 一个已经存在的谓词

片段 · 导出 handler 的角色闸（判定仍收在 platform/authz）func (h *ExportHandler) ExportCSV(c *gin.Context) {
    a := actorFrom(c)
    if !authz.CanExport(a.Role) {                       // 唯一新代码：guest → false
        response.Fail(c, http.StatusForbidden, response.CodeForbidden, "当前角色不可导出") // 403 + 1003
        return
    }
    // …其余与昨天完全一致：parseListQuery → ListAll（内含 is_private 谓词）→ CSV
}

私密行的过滤一行都不用新写：D13 把可见性谓词接进了查询构造器，导出的 ListAll 走的就是它。这正是「判定只有一份实现」的复利——昨天在列表上验证过的谓词，今天在导出上自动生效；明天报表再消费同一个构造器，还是自动生效。

反面实现是把导出范围写成 WHERE member_id = 当前用户「先安全一把」——那不是安全，是口径错误：它把 member 应得的家庭全量砍成个人流水，同时又没挡住 guest（guest 也有 member_id）。安全靠角色闸 + 可见性谓词两件正牌工具，不靠随手加过滤。

3. 审计一笔带过

导出是「数据出院」动作，值得在审计日志里落一行（谁、何时、什么筛选、多少行）。审计落库不落查询接口（管理台不在范围内），教学期用结构化日志打一行即可——S5 建的日志件正好用上。这是选做加分项，不进判据。

步骤 1 · authz 补 CanExport

片段 · server/internal/platform/authz/finance.go// CanExport 财务数据导出闸：guest 不可导出，其余角色可。
func CanExport(role model.Role) bool {
    return role != model.RoleGuest
}

import (
    "encoding/csv"
    "net/http/httptest"
    "strings"
    "testing"
)

func TestExportRoleScope(t *testing.T) {
    r, tk := newTestRouter(t)
    // seed：memberA 记 2 行（1 行私密）、memberB 记 2 行（1 行私密），同家庭同月份
    seedFourRowsTwoPrivate(t, r, tk)

    export := func(token string) (rows [][]string, code int, bizCode int) {
        w := httptest.NewRecorder()
        req := newAuthRequest(t, "GET", "/api/finance/reports/export?period=2026-03", token)
        r.ServeHTTP(w, req)
        if ct := w.Header().Get("Content-Type"); strings.Contains(ct, "text/csv") {
            rows, _ = csv.NewReader(strings.NewReader(strings.TrimPrefix(w.Body.String(), "\ufeff"))).ReadAll()
            return rows[1:], w.Code, 0
        }
        return nil, w.Code, decodeBizCode(t, w.Body) // JSON 信封 → 业务码
    }

    ownerRows, _, _ := export(tk.Owner)
    if len(ownerRows) != 4 { t.Fatalf("owner 应导全量 4 行, got %d", len(ownerRows)) }

    aRows, _, _ := export(tk.MemberA)
    if len(aRows) != 3 { t.Fatalf("memberA 应导 3 行（B 的私密行不可见）, got %d", len(aRows)) }
    for _, row := range aRows {
        if isPrivateOfOther(row, "memberB") { t.Fatal("memberA 的导出漏进了 B 的私密行") }
    }

    _, status, biz := export(tk.Guest)
    if status != 403 || biz != 1003 { t.Fatalf("guest 导出应 403+1003, got %d+%d", status, biz) }
}

坑现象正确姿势

今日名词卡

术语一句话解释
导出权限口径导出的行集合 = 该读者列表可见集合；guest 整体拒绝
只导自己（反模式）把导出砍成个人流水，与列表不一致——事故的下半场
角色闸接口级开关（CanExport）；与行级谓词是两层不同的工具
行级谓词D13 的可见性过滤，长在查询构造器里，导出自动继承
1003权限不足（403）：角色矩阵拒绝、guest 导出、非作者改他人私密数据
404 同形 vs 403 拒绝行级藏存在性用 404+1001；接口整体关门用 403+1003
四级角色owner / member / ward / guest；guest 限时只读、不可导出、可撤销
判定单一实现的复利谓词写一次，列表/导出/将来的报表全部自动生效
数据出院审计导出落一行结构化日志（谁/何时/何筛选/多少行）；选做加分项

卡壳时查什么
