> **这份文件存"怎么变成现在这样的"，不存"要做成什么样"。** 现行规格全部在 `docs/prd/prd-homecube.md`（唯一权威需求文档）；本文件按定版轮次归档每一次的行内变更史——原句曾写作什么、改成什么、为什么、代价是什么。
> **归档原则是剪切不重写**：正文里删掉的每一段原文在本文件必须能逐字查到，出处标注为「章节号 + 定版轮次」。

> **已移出当前施工范围的五个业务面**（采购 / 饮食 / 出行 / 家人 / 成长）的墓碑正文、存档索引与验收枚举，归档在本文件末段的「已移出的五个面」；其**全量需求原文**不在此重写，一律从 PRD 定版 ㉚ 口径的版本历史取回。
