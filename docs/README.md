## 三份文档，按这个顺序读

```
1. docs/prd/prd-homecube.md      需求真源（23 章）—— 想做什么
       ↓ 想做什么
2. docs/tech-plan.md             技术方案 —— 怎么做
       ↓ 做成什么形状
3. docs/plan/learning-plan.md    学习与施工计划 —— 什么时候做什么
```

本站以「结合项目知识库学习」为首要目的：PRD 与技术方案是**可回溯真源**，不是读完即可搁置的背景资料。
日卡会带结构化出处字段 `refs[{doc, section, quote}]`，学习者从卡上直接跳回 PRD 对应小节的原文，先读原文再做题。

## 三条最容易踩的坑

1. **金额用整数分，不用浮点** —— 浮点在累加与比较上必然出偏差
2. **越权返 404 不返 403** —— 403 等于告诉攻击者「东西存在」
3. **未设预算就显「未设」，不折算** —— 禁止把月度预算乘 3 造一个假数字
