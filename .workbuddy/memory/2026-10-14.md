### 三个重要的技术发现
1. **Vite 7 在这台机器上构建失败**（`Cannot find module '@rolldown/binding-darwin-universal'`）→ 降到 `vite@5.4.11` + `@vitejs/plugin-react@4.3.4` 正常。
2. **Go 其实装了**：`~/.workbuddy/binaries/go1.22.5/bin/go`（go1.22.5 darwin/amd64）。第一轮agent 误以为没装，代码靠手核；发现后建了 `/tmp/s3v` 验证沙箱，**22 个 Go 程序全部真跑两遍比对 md5**，抓出 8 个手写必漏的 bug。**后续所有日卡的 Go 代码都必须真跑验证。**
3. **GORM DryRun 可离线生成真实 Postgres SQL**（`gorm.io/driver/postgres@v1.6.0` + pgx v5.6.0，配 `DisableAutomaticPing: true`），配合 `db.ToSQL()` 与 `NowFunc` 固定时钟，输出可确定。S3 的 SQL 由此真跑得出。
   - 版本坑：pgx v5.11 / gorm postgres v1.6.2 要 Go 1.25，本机 1.22.5 装不了。
