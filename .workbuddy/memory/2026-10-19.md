## 关键复用约定
- 路线内容全部在 `web/src/roadmap/content/*.md`，改内容不碰组件；阶段元数据在 `data.ts`。
- 每日任务数据在 `web/src/roadmap/days/phaseN.ts`，加/改某天只动这一个文件。
- 每日讲解在 `web/src/roadmap/lessons/phaseN.md`（阶段五另加 `phase5b.md`，在 `lessons/index.ts` 的 `sources` 里按数组拼接），用 `<!--day N | depth-->` 分节；新增一天必须同时补 days 与 lessons。
- 掌握闭环在 `web/src/roadmap/mastery/phaseN.md`，`<!--day N-->` 分天、`::pre/::predict/::debug/::sym/::ask/::ans/::transfer/::scene/::hint/::crit` 指令；新增一天必须同时补 days / lessons / mastery 三处，否则该天缺环节。
- 进度存 `localStorage['family-ledger-roadmap:progress:v4']`，任务 id = `p{阶段}-d{天}-t{序号}`，判据 id = `p{阶段}-d{天}-k{序号}`，验收 id = `p{阶段}-a{序号}`，预测草稿存 `['family-ledger-roadmap:guesses:v1']`。
- 自测必须写在每天讲解的**最后**，格式 `::q 问题` / `::a 答案`（答案可换行，到下一个 `::q` 结束）；解析器会把自测从正文里剥出来单独渲染。
- 用户对「工具/站点可用性」要求极高，必须真实渲染验证（DOM/截图），不接受仅编译通过；且反感「用长度冒充深度」，讲深度必须落到可验证机制（自测/判据/对照代码）。
- 本机 headless Chrome 带 `#hash` 截图会得到空白图；改用「临时 html + CSS 隐藏其他 section」的办法截取目标区块（用完即删）。
