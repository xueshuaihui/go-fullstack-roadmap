课前须知：给 JS 开发者的三句话

1. 编译型语言。Go 代码先编译成一个可执行文件才能运行，没有 node xxx.js 这种"边解释边跑"。好消息：go run 命令把编译+运行合成了一步，体感和 node 几乎一样。

2. 类型在写代码时就定死。int 变量不可能在下一行变成字符串。parseInt("abc") 返回 NaN 继续往下传的事故，在 Go 里会以"编译失败"的形式当场暴露。

3. 没有 try/catch。函数出错时不会"抛出"，而是把错误当作普通返回值给你：result, err := doSomething()，你必须当场检查 err。这是 Go 最有争议也最重要的设计，今天先养成肌肉记忆。

知识讲义

1. 安装 Go（约 15 分钟）

打开官网下载页 go.dev/dl，下载对应你系统的安装包（Windows 用 .msi，macOS 芯片为 M 系列选 arm64、Intel 选 amd64，Linux 用 .tar.gz）。

系统安装方式验证
Windows双击 .msi 一路下一步（默认加入 PATH）新开终端执行 go version
输出如 go version go1.24.x windows/amd64 即成功
macOS双击 .pkg，或 brew install go
Linuxtar -C /usr/local -xzf go*.tar.gz 后把 /usr/local/go/bin 加入 PATH

编辑器装 VS Code + Go 官方扩展（扩展 ID golang.go）。装完扩展会提示安装 gopls 等工具，点 Install All 即可。它有代码补全、格式化、错误提示，和写 TS 的体验差不多。

不需要配置 GOPATH——那是 Go 1.11 之前的老古董。现在只认 Go Modules，任何目录都能写 Go。

3. 变量、常量

main.gopackage main

import "fmt"

func main() {
    // 写法一：完整声明（函数外只能用这种）
    var name string = "learner"

    // 写法二：类型可推断
    var age = 25 // int

    // 写法三：短声明，仅限函数内部，最常用（≈ 有类型的 const 之外都用它）
    city := "Hangzhou"

    // 声明了不用 = 编译错误！Go 不允许死变量
    // unused variable 'x' 会直接报错，而不是 warning

    fmt.Println(name, age, city)
}
shell$ go run .
learner 25 Hangzhou

常量用 const；配合 iota 可以生成一组自增枚举（Go 没有 enum 关键字）。下面这段写在 func main 的外面（函数上方），再在 main 里 fmt.Println(StatusDraft, StatusPublished) 验证：

main.goconst (
    StatusDraft int = iota // 0，iota 在 const 块内逐行 +1
    StatusPublished          // 1（自动继承上一行的表达式）
    StatusArchived           // 2
)

const Pi = 3.14159 // 常量不可修改，编译期求值

对比 JS：let/const 的区别是"能否重新赋值"；Go 的 var 和 := 的区别只是写法（都能重新赋值），真正不可变的是 const。

4. 基础数据类型速查

类别类型说明 / 与 JS 对照
整数int int8/16/32/64，uint 系列一般无脑用 int；JS 里所有数字都是 float64，Go 整数除法会截断：5/2 == 2
浮点float64 float32默认用 float64，与 JS 的 Number 同精度
字符串string不可变；"%s是%s" 用 fmt.Sprintf 拼接；长度用 len()（按字节！中文 3 字节）
布尔bool只有 true/false，不能用 if 1 {} 或 if "" {} 做真值判断
零值—声明未赋值的变量必有默认值：数字 0、字符串 ""、bool false。没有 undefined/null 这两个坑

下面这份是完整可运行的 main.go。今天起每个示例都按同一个方式跑：覆盖 main.go → go run .（一个 package main 里只能有一个 func main，所以别把两节的代码叠在同一个文件里）。

main.gopackage main

import "fmt"

func main() {
    // 类型转换必须显式，Go 不做隐式转换
    var i int = 10
    var f float64 = float64(i) / float64(3)
    fmt.Println(f) // 3.3333333333333335（写成 i/3 得 3，整数除法会截断）

    // 字符串 ≠ 数字，"5" + 5 直接编译失败
    s := fmt.Sprint(5) + "abc"
    fmt.Println(s) // 5abc，需要转字符串用 fmt.Sprint
}
shell$ go run .
3.3333333333333335
5abc

5. 控制流：if / for / switch

main.go（完整可跑，覆盖上一节）package main

import "fmt"

func main() {
    // if 的条件不需要括号，但必须是大括号块
    if score := 85; score >= 90 {
        fmt.Println("A")
    } else if score >= 60 {
        fmt.Println("B") // ← 命中这里；score 只在 if/else 作用内存活
    } else {
        fmt.Println("C")
    }

    // for 是 Go 唯一的循环关键字：
    for i := 0; i < 3; i++ { fmt.Println(i) } // 经典三段式 → 0 1 2
    n := 0
    for n < 5 { n++ }                          // 相当于 while，结束后 n=5
    for { break }                               // 相当于 while(true)，用 break 退出

    // switch 默认自带 break（不会穿透），且 case 可以是任意表达式
    day := "Saturday" // 先声明再 switch；day 必须是 string，否则 case 匹配不上
    switch day {
    case "Saturday", "Sunday":
        fmt.Println("周末写项目") // ← 命中这里
    default:
        fmt.Println("工作日学习")
    }
}
shell$ go run .
B
0
1
2
周末写项目

range 初识（明天开始天天用，今天先会这三种写法）：遍历 slice / map / 字符串用 for 下标, 值 := range 集合，两个变量按位置分别是下标和元素；不要哪个就写 _ 丢掉：

main.go（继续覆盖）package main

import "fmt"

func main() {
    scores := []int{90, 85, 77} // 这是一个 int 切片（Day 3 细讲）

    for i, v := range scores {  // 下标 + 值都要
        fmt.Printf("第 %d 个是 %d\n", i, v)
    }

    for _, v := range scores {  // 只要值：下标用 _ 丢弃
        fmt.Println(v * 2)
    }

    for i := range scores {     // 只要下标（Day 3 改元素本体就靠它）
        fmt.Print(i, " ")
    }
    fmt.Println()
}
shell$ go run .
第 0 个是 90
第 1 个是 85
第 2 个是 77
180
170
154
0 1 2

三个高频编译错误先打预防针：① if x = 1 {}（写错赋值符号）；② 条件写成 if 1 {}（非 bool）；③ 行尾大括号换行——Go 要求 } 或 else 不能独占一行开头，格式化工具 gofmt 会自动修正，保存时让编辑器格式化即可。

6. 多返回值与 error：Go 的灵魂

JS 里函数出错靠 throw，调用方 try/catch；Go 里函数把"结果"和"错误"一起返回，调用方必须当场处理：

main.gopackage main

import (
    "errors"
    "fmt"
)

// 返回值签名 (int, error)：要么给结果，要么给错误
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("除数不能为 0")
    }
    return a / b, nil // nil ≈ 没有错误（相当于 null，但仅限指针/接口类型）
}

func main() {
    result, err := divide(10, 0)
    if err != nil {          // ← Go 最经典的两行，全宇宙到处是它
        fmt.Println("计算失败:", err)
        return
    }
    fmt.Println("结果:", result)
}
shell$ go run .
计算失败: 除数不能为 0

上面注释里有两个词现在只需要最小定义：指针≈JS 里对象的"引用"——它存的是变量的地址，&x 取地址、*T 声明"这是个指向 T 的指针"，顺着地址改就等于改原对象（本周 Day 2 正式讲）；接口=一组方法名的约定，error 就只约定了 Error() string 一个方法，谁的类型有这个方法谁就算实现了它（本周 Day 4 正式讲）。

习惯它。以后写 Web 后端，"参数错了返回 400、数据库挂了返回 500"全部建立在 if err != nil 这个模式上。错误就是值（errors are values），可以传参、可以包装、可以单元测试。
