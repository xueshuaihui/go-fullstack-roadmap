| 阶段 | 周数 | 核心内容 | 验收标准 |
| :--- | :--- | :--- | :--- |
| **一** | 2–3 周 | Go 语法、错误处理、接口、SQLite | 命令行账本，关掉终端数据还在 |
| **二** | 1–2 周 | goroutine、channel、竞态、`context`、分包 | `-race` 报告出现又消失 |
| **三** | 3 周 | `net/http`、路由、中间件、REST、统一响应、分页 | curl 增查，重启不丢，分页可用 |
| **四** | 2 周 | 密码哈希（Argon2id / bcrypt cost 12）、JWT、认证中间件、数据隔离 | A 看不到 B 的账，响应无密码字段 |
| **五** | 4–5 周 | 分层、GORM（**`Session` 隔离 + 请求级 `Context` 字段**）、迁移、连接池、统计、预算、CSV 导出、测试、集中错误处理、结构化日志 | `go test` 全绿，迁移可执行，日志带 request ID |
| **六** | 2–3 周 | 配置管理、Docker、优雅关闭（**Server 超时 + Shutdown 顺序**）、健康检查、CORS、**govulncheck**、**Cookie 安全 + CSRF** | 手机浏览器完成完整操作，服务可优雅停止，无已知依赖漏洞 |
